# Nota del modelo

La fase 0 usa un conectoma sintético para probar el pipeline. No permite afirmar ninguna ventaja biológica. El modo Hemibrain requiere una fuente neuPrint configurada y documentar el subgrafo utilizado antes de cualquier comparación.

El cuerpo virtual (`FlyBody`) es una capa lúdica de estado/visualización: energía, alas, orientación y posición. No es una simulación anatómica ni aporta información adicional al modelo salvo que se conecte explícitamente en una fase posterior.
